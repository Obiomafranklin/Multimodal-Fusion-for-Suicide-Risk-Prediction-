# Multimodal-Fusion-for-Suicide-Risk-Prediction-
The purpose of this research study is to construct a multimodal machine learning pipeline that fuses structured electronic health record (EHR) data with unstructured clinical notes to predict 90-day suicide risk in a behavioral health population. The model has been designed with interpretability as a core requirement, using SHAP (SHapley Additive exPlanations) for structured features and LIME for text features. The primary data source for this project is the MIMIC-III (Medical Information Mart for Intensive Care III) Clinical Database, version 1.4. MIMIC-III is a large, freely available, and de-identified EHR dataset comprising information on over 40,000 patients who stayed in critical care units at the Beth Israel Deaconess Medical Center in Boston, Massachusetts, between 2001 and 2012. The dataset contains both detailed structured tables (e.g., PATIENTS, ADMISSIONS, DIAGNOSES_ICD, PRESCRIPTIONS) and a wealth of unstructured clinical notes in the NOTEEVENTS table, including discharge summaries, physician notes, nursing notes, and social work notes. An entity relationship diagram was designed and created on a relational database to house the datasets, and with the help of the patient and admission IDs, the datasets were initially combined and grouped inside a structured data architecture. This was done in order to establish appropriate connections.
The data acquisition method consisted of importing datasets into a PostgreSQL database and then running structured queries in order to retrieve information that was pertinent to the subject matter. The process of managing missing information, standardizing date formats, and computing derived attributes such as admission age and length of stay were all essential components of the data cleansing process. In order to handle the unstructured clinical notes, additional methods such as filtering relevant categories, deleting extraneous content, and consolidating language at the admission level were utilized.
The utilization of data integration strategies, which included the use of numerous join methodologies, was done in order to guarantee the comprehensive amalgamation of all data sources. Inner joins were used to aggregate the data from admissions and notes, whereas left joins were used to save the information from individual patients. The purpose of utilizing aggregation techniques was to integrate a large number of notes into a single document for each admission. This allowed us to conduct a more effective analysis of the content.
With the use of an exploratory data analysis, we were able to identify patterns and assess the overall quality of the data. The analysis of feature distributions brought to light variations in age and length of hospital stay between the groups that were considered to be at high risk and those who were considered to be at low risk. This was in contrast to the examination of temporal trends, which revealed changes in the number of suicides over time. When conducting the first text analysis, it was discovered that key terms related with suicide risk were discovered as a result of an evaluation of the linguistic patterns that were observed in clinical notes.
The modeling technique takes into account both structured and unstructured data in combination with one another. When evaluating structured data, we make use of XGBoost, and when analyzing text data, we make use of techniques that are associated with natural language processing. Considering that the models are integrated through the use of a late fusion method, the system is able to make use of both numerical and textual information in order to increase the accuracy of its predictions.
Managing class imbalance, dealing with missing data, and processing enormous amounts of text data were just a few of the obstacles that the project faced. Additional challenges included dealing with missing data. Regardless of these obstacles, the approach demonstrates a great deal of potential for enhancing the prediction of suicide risk through the utilization of multimodal analysis.
The purpose of this project is to enhance clinical decision-making by building a framework that can be replicated for the purpose of integrating various healthcare data sources. Additionally, this framework will make it possible to generate projections that are more accurate and clear.
